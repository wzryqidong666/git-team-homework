# Juliet977 作业
## 思考题
1. 简述git add命令的作用。
答：git add 把工作区的改动添加到暂存区，让git追踪这个文件的修改，准备提交。

2. 简述git commit命令的作用。
答：git commit 将暂存区里的改动保存成一个版本快照，存入本地git仓库，生成提交记录。

3. git restore的作用是什么？本次实验中两次restore分别做了什么？
答：git restore用来撤销文件修改。第一次：撤销notes.md新增的文字，恢复到暂存区版本；第二次：恢复被删除的plan.md文件。

4. 工作区、暂存区、本地仓库三者的区别？
答：工作区：你直接看到、编辑的文件；暂存区：临时存放待提交修改的区域；本地仓库：存放所有历史版本快照的地方。

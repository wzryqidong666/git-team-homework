学习 Git 版本控制管理后，我理解了版本控制对协同开发的重要意义。Git 作为分布式版本控制系统，依靠快照存储与哈希对象实现高效版本管理。我掌握了工作区、暂存区、版本库三者关系，熟悉提交、分支、合并等基础命令。懂得借助 Git 追溯修改、处理冲突，规避手动备份带来的版本混乱问题，为今后开源项目协作打下基础。

### 对git add、git commit、git restore的理解
1. git add：将工作目录的修改加入**暂存区**，标记文件准备提交，并不会真正生成版本。
2. git commit：把暂存区的改动保存到**本地版本库**，生成一条完整提交快照，仅作用于本地。
3. git restore：撤销工作区的修改，将文件恢复为暂存区里的状态，丢弃未暂存的改动。

# 我的 Git 学习笔记

## 第一次 Git 实验总结
1. `git add` 的作用是：将工作区中修改或者新增的文件添加到**暂存区**，标记这些文件准备提交，并不会保存到版本库。
2. `git commit` 的作用是：把暂存区里的文件快照提交到**本地Git版本库**，生成一条新的版本提交记录，永久保存本次改动。
3. 本次实验中 `git restore notes.md` 的作用是：用版本库中的文件覆盖工作区的 notes.md，撤销工作区还没有执行 git add 的临时修改，丢弃本地未暂存的改动。
4. `commit` 与 `push` 的区别是：`commit` 只把改动保存到**自己电脑的本地仓库**，不会上传网络；`push` 将本地已经 commit 完成的提交记录上传推送到 GitHub 远程仓库，让团队其他人可以获取到你的代码。
